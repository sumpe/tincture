# The Tincture Project

Grammar drills games.

- **[Polyverb](polyverb/)**: verb conjugation in Portuguese, Polish and Swedish.
- **[Polynoun](polynoun/)**: noun plurals, cases and gender in Portuguese, Polish and Swedish.

Nothing to install: open `index.html` in a browser.

Site: https://sumpe.github.io/tincture/

## History

This repo was `sumpe/polyverb`, renamed. Polynoun's history, from
`sumpe/polynoun` (now archived), was merged in with its commit IDs unchanged.
